# ArteBid — Digital Collectibles Auction Platform

ArteBid is a UI/UX case study and interactive prototype for a digital collectibles platform.

The concept combines an online auction platform with marketplace and social interaction features, allowing users to discover digital collectibles, participate in auctions, manage their collections, and interact with other users.

## Case Study

The ArteBid concept was developed as a UI/UX design study to explore the design of a digital collectibles platform and its user experience.

The design focuses on several aspects of the user journey, including discovering collectibles, viewing auction details, participating in auctions, creating auction listings, payment confirmation, notifications, and user profiles.

## Main Concept

ArteBid combines three main concepts:

* **Auction** — Users can participate in digital collectible auctions.
* **Marketplace** — Users can discover and explore digital collectibles.
* **Social Interaction** — Users can interact through profiles, followers, comments, and other social features.

## Designed Features

The prototype explores several application flows and interfaces, including:

* Home / Dashboard
* Explore and search
* Digital collectible discovery
* Auction detail
* Create auction
* Payment confirmation
* Notifications
* User profile
* Followers and following
* Comments and interaction
* Collection-related interfaces

## Design Tool

* Figma

## Project Type

**Individual UI/UX Case Study / Interactive Prototype**

This project focuses on UI/UX design, user flow, and interactive prototyping rather than application development.
